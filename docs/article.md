# 为了让一个镜头真正恢宏，我做了东方巨物、关键词扩展和近 500 条 Prompt 漫游

我最开始只是想做一种真正“大”的视频。

不是把画面里写满“史诗级、8K、PBR、体积云”，也不是生成一座很高的宫殿就结束，而是让观众在镜头运动起来以后，仍然能感受到前景、中景、远景、人物和巨构之间那种压倒性的尺度差。

后来我才发现，最难的其实不是生图，而是运镜。

一张图片可以很宏大。可它一旦变成视频，镜头可能只是机械地慢推，云层像开水一样翻滚，宫殿会弯曲增生，人物越走越大，原本很震撼的空间反而会在几秒内塌掉。

所以最先出现的并不是关键词扩写，也不是 Prompt 题库，而是第一套 Skill：

> 怎样把一张东方巨物母图，变成一个真正恢宏、稳定、有前后景视差的电影镜头？

这就是 `hbg-oriental-giant-world` 的起点。

第二个问题才是灵感。

不是每个人脑子里都有一整座世界。很多时候，用户只有一个国家、一个宗教、一个动作，甚至只是一句很稀碎的感觉：“泰国”“印度尼西亚”“弹琴”“月球”“我想要很大、很荒诞”。

为了让这种碎片也能开始创作，我又做了 `hbg-keyword-giant-world`。它真正的核心不是“把关键词补充完整”，而是：**万物皆可巨构。**

但很快又出现第三个问题。

关键词巨构转义出来的画面，不一定就是用户真正想要的“中国东方巨物”感觉。

例如输入“泰国”，最合理的扩展可能是泰式佛塔、热带河流、那伽、金色屋顶和季风云墙。它可以非常壮观，但它未必适合白玉天阶、云上宫阙、天门、巨月和中国神话那种视觉语言。如果为了“东方”两个字，强行把泰国全部换成中国天宫，文化身份又会被抹掉。

于是我把 475 条东方巨物 Prompt 原文放进漫游题库，用它们学习不同的奇观机制、尺度关系、天空与天体用法、构图和镜头可能性。

这些 Prompt 不是最后要照抄的风格，而是一套可以漫游、学习和重新出题的题库。

这就形成了第三套 Skill：`hbg-oriental-giant-roam`。

开源项目：<https://github.com/Mr-funny/hbg-epic-giant-worlds>

## 零、这三路 Skill 的真实出现顺序

| 顺序 | Skill | 它最先解决的问题 |
|---|---|---|
| 1 | `hbg-oriental-giant-world` | 怎样让图片和视频都保持恢宏的东方巨物感觉，尤其是运镜 |
| 2 | `hbg-keyword-giant-world` | 万物皆可巨构：怎样把一个词或一团碎片灵感转义成荒诞的世界级巨构 |
| 3 | `hbg-oriental-giant-roam` | 不喜欢当前关键词方向、没有关键词，或想从近 500 条 Prompt 中寻找新题目时怎么办 |

它们并不是三套互相替代的 Prompt。

更准确的关系是：

```text
已有画面或想法
→ 东方巨物风格与恢宏运镜

只有一个词或碎片灵感
→ 关键词巨构转义
→ 排除现实中可能存在的普通景观
→ 再决定是否进入东方巨物风格

不知道想做什么，或者不喜欢关键词扩展的方向
→ Prompt 题库漫游
→ 抽取奇观语义
→ 重新改写成东方巨物图片与视频
```

最难的是让世界动起来仍然成立；最常见的是用户没有完整灵感；最后才是通过题库扩大创作范围。

## 一、最困难的不是生图，而是恢宏运镜

单张巨物图很容易制造第一眼冲击。

放一个巨像，人物缩小，建筑放大，再加上云海和月球，静态画面就已经很震撼。

但视频有一个残酷的问题：它会把所有空间漏洞暴露出来。

我遇到过几种很典型的失败。

### 1. 所有镜头都是“慢推 + 云飘”

第一张桥梁慢推，第二张宫殿慢推，第三张巨像还是慢推。单独看都没有错，拼在一起却像同一个镜头换了四张壁纸。

宏大并不等于镜头永远向前。

不同空间应该有不同的发现方式：

| 母图结构 | 更适合的运镜 |
|---|---|
| 长桥、天阶、河流 | 沿引导线缓慢推进 |
| 高位俯瞰的峡谷、城市、卷轴山河 | 缓慢下降或斜向揭示 |
| 巨型庭院、风铃塔、神殿外墙 | 横向移动配合轻微抬升 |
| 船、码头、海面与洞窟城市 | 贴水跟随前进 |
| 曼陀罗、莲台、环形祭城 | 有克制的高位下降，不能快速旋转 |

运镜必须来自画面本身，而不是每次都复制一句通用模板。

### 2. 镜头越快，巨物反而越小

快速飞越、猛烈升空、环绕巨像，看起来很热闹，但它会把巨构变成一个可以轻易绕过去的普通模型。

真正恢宏的镜头往往很慢。

前景栏杆、索具、船头和岩壁移动得明显；中景平台和人物移动得较少；远处神山、天宫、月球和地球几乎不动。

观众会通过这种速度差感到：远处的东西并不是没有动，而是大到镜头的移动不足以改变它。

这才是巨物感。

### 3. 图片里的建筑，到了视频里开始生长

如果把生图 Prompt 原封不动交给视频模型，模型会认为自己需要在八秒内重新创造一次这个世界。

结果可能是：

- 宫殿增加新的楼层。
- 栏杆变软、弯曲或融化。
- 神像换脸，手臂数量变化。
- 桥梁突然延长。
- 人物复制、放大或转成主角特写。
- 月球和地球开始移动、旋转或膨胀。

所以图生视频 Prompt 的核心不是继续描写世界，而是规定哪些东西绝对不能改变。

```text
远景巨构：刚性锁定
建筑轮廓：刚性锁定
天体位置：刚性锁定
人物数量和位置：锁定
一种主运镜：允许
一类环境运动：允许
一个微小人物动作：允许
其他增生和改造：禁止
```

### 4. 恢宏感来自前后景关系，不是来自大词

一段稳定的东方巨物运镜，通常需要这几层同时存在：

```text
近处可读的材质或结构
+ 中景人物舞台
+ 极小人物
+ 一座主巨构
+ 大面积云、海、山、天空或天体
+ 只服务于这些层级的一种镜头运动
```

例如“天穹龙脊桥”这一镜：

- 近处白玉桥面和古铜栏杆产生最快视差。
- 五名人物只走一两步，始终很小。
- 云层分成不同速度缓慢移动。
- 远处地球弧面绝对稳定。
- 摄影机只沿桥贴地慢慢推进。

运镜不是给静态图片加一个动画，而是在重新证明这座空间确实巨大。

这就是为什么最先需要的是东方巨物 Skill。

## 二、东方巨物 Skill 固定的不是一棵树和一座天宫

最早的一版模板很稳定：右侧古松、右下白玉平台、左侧云海、远处天宫。

单张非常漂亮，但用户很快指出：

> 不要总是有一棵树，太单一了。

后来还有一句更重要的纠正：

> 你的运镜部分、布景部分都需要有这种磅礴的感觉，而且前后景、景别、布景都不要单调。

这说明东方巨物不能固化成一张构图模板。

它应该固定的是视觉 DNA：

- 明亮、空灵、祥瑞、庄严、遥远、令人向往。
- 蓝白空气、真实雾霭、自然体积光和暖金晨昏。
- 象牙石、浅玉、古木、朱红、古铜、克制淡金和地域材料。
- 极小人物、一个主巨构、大面积环境留白。
- 稳定、缓慢、具有层级视差的镜头运动。
- 不默认黑暗、恐怖、末日、死黑前景和怪兽攻击。

而下面这些必须变化：

- 前景是建筑、地貌、水、天气、雕塑、工艺还是开放空间。
- 摄影机是贴地、平视、斜俯视、鸟瞰还是近垂直俯拍。
- 巨构出现在左侧、右侧、远方、脚下还是山体内部。
- 引导线是桥、河、阴影、道路、瀑布、阶梯还是环形结构。
- 运镜是推进、横移、抬升、下降还是贴水靠近。

“风格固定”不等于“构图固定”，更不等于“每张都有一棵古松”。

## 三、第二个问题：不是每个人都有完整灵感

解决运镜以后，新的问题出现了。

用户不一定会给出一份完整导演稿。更多时候，输入可能只有：

```text
泰国
印度教
印度尼西亚
道教
弹琴
月球
我想要一个很荒诞的巨物
```

这不是用户表达不清楚，而是创意本来就经常以碎片形式出现。

如果 Agent 要求用户先补齐人物、建筑、光线、机位、材料和运镜，那实际上把最困难的工作又推回给了用户。

所以我做了 `hbg-keyword-giant-world`。

它最关键的一句话不是“关键词扩写”，而是：

> 万物皆可巨构。

国家、宗教、人物、动物、植物、动作、声音、器物、材料、影子、洞口、衣服褶皱，甚至“等待”“记忆”这种抽象概念，都可以不再只是场景里的一个元素，而是直接变成地貌、城市、天穹、天气、基础设施或新的物理法则。

这和“把一个东西放大”不是一回事。

对比几种很容易出现的结果：

- 真实寺庙后面出现一座喷发的火山，很壮观，但现实中可能拍到。
- 海边石门通向悬崖宫殿，很漂亮，但仍然像旅游景观。
- 山谷村落上方出现夸张的大屋顶，有奇幻感，但本质还是放大的建筑。

这些画面解决了“宏伟”，没有解决“荒诞巨物”。

真正舒服的巨物感来自对象发生了类别变化：

- 一张山岳尺度的石质面孔本身就是城市，桥梁穿过眼眶，村落生长在眉骨，泪痕成为瀑布。
- 一只安静的巨兽不是从天空飞过，而是腹部直接成为整座世界的天穹，神殿柱群托住它，人类在其下方生活。
- 柱廊不只是特别高，而是真的支撑着云海；云从柱间溢出，在宫殿边缘变成贯穿天地的瀑布。

这里有一句必须固化进 Skill 的判断：

> 概念必须不可能，材质和光影必须写实。

如果画面去掉“8K、电影感、史诗级”以后，仍然只是一个现实景区，那么就要退回去重新转义。

每个关键词现在会进入这些槽位：

```text
关键词类型
核心精神
代表性地貌
建筑或工程语言
材料与工艺
纹样或象征
人物的安静动作
要拒绝的现实版本
关键词本身变成什么
至少两种类别怎样融合
一个不可能法则
这个法则造成的两项环境后果
人类怎样在巨构内部、表面或下方生活
至少三条尺度证据
时间、天气与自然光
可选的单一天空或天体锚点
文化禁忌与错误边界
荒诞度评分，至少 8/10
```

例如“印度尼西亚”可以被扩展为：

```text
印尼守护石雕 × 山岳面孔 × 群岛水利城市
眼眶成为跨海长桥，眉骨承载梯田村落，古老泪痕形成季风瀑布
```

“弹琴”也可以不再只是一个人物特写，而是：

```text
一张横卧云海的大陆尺度古琴
+ 琴腹内部是一座拥有天空和河流的峡谷城市
+ 琴弦每次震动都会抬起承载村落的山脉波纹
+ 微小琴师只是远处负责校音的人，而不是人物特写主角
```

关键词巨构转义解决的是“任何东西怎样变成一个世界”，而不是给现实景观继续堆宏大形容词。

## 四、第三个问题：关键词合理，不代表它就是你想要的画面

关键词扩写有一个天然限制：它首先要尊重关键词本身。

输入“泰国”，合理的视觉语言应该来自泰式佛塔、热带水系、金色屋面、那伽、季风天空和当地人物活动。

它未必会自动长成“中国云上宫阙”。

如果用户真正想要的是白玉天阶、南天门、云海、巨月和中国神话建筑，那么“泰国”可能只是一次不合适的灵感入口。

这里不能用两种偷懒方式解决：

1. 不能把泰国所有东西简单替换成中国飞檐，那会丢失题材身份。
2. 也不能坚持“既然输入了泰国就必须一直做泰国”，因为用户可能只是想寻找视觉冲击，并不喜欢这个方向。

所以系统需要两条路。

### 路线 A：保留泰国，但使用东方巨物电影语法

保留泰式建筑、热带生态和文化行为，只统一这些部分：

- 明亮空气和暖金自然光。
- 微小人物与主巨构的尺度关系。
- 前中后景分层。
- 关键词必须发生类别转义，不能停留在真实寺庙、火山、海门或村落。
- 至少一个不可能法则和两项可见环境后果。
- 一个宇宙或天气锚点。
- 稳定、克制、恢宏的运镜。

这是“题材不变，电影语法统一”。

### 路线 B：放下当前关键词，去题库里寻找另一个问题

如果用户并不喜欢泰国方向，就不应该继续在同一个关键词上反复换皮。

这时更好的方法是进入漫游模式：从大量巨物 Prompt 中抽取新的奇观题目，例如巨桥跨过地球弧面、无字经卷形成山脉、山体内部是一座城市、巨门的影子覆盖整片文明。

然后再把这些题目统一改写成用户真正喜欢的中国东方巨物风格。

这就是漫游模式存在的原因。

## 五、我公开了 475 条东方巨物 Prompt 原文，不是为了照抄

为了让漫游模式不是凭空随机，我把 475 条东方巨物 Prompt 原文直接放进了公开题库。

这批 Prompt 最有价值的并不是原句，而是其中反复出现的视觉机制：

- 人类像蚂蚁一样小。
- 一件普通器物变成大陆或城市。
- 宫殿、神像、山体和交通系统融合。
- 云海、地球、月球和日食提供熟悉尺度。
- 近处文化细节与远处宇宙空间同时出现。
- 正常重力与倒悬城市等两套空间规则并存。
- 巨物完整展示，但通过广角 proximity、阴影、道路和空气透视建立尺度。

用户也明确指出：

> 这些提示词并不是我现在最想要的那个风格。

所以它们只能作为题库，不能成为最终风格母版。

## 六、漫游模式不是复制 Prompt，而是把 Prompt 变成题目

漫游模式把每条 Prompt 分成三层。

### 第一层：来源档案

保存原始 Prompt、来源页面、作者和内容哈希。它属于来源记录，不能覆盖，也不能伪装成新的原创 Prompt。

### 第二层：语义核

只提取：

- 这条 Prompt 最核心的奇观是什么。
- 它使用了什么尺度机制。
- 人物和巨物是什么关系。
- 哪个空间矛盾最有冲击力。
- 哪些内容属于文化事实，哪些只是来源作者的画风。

### 第三层：东方巨物适配

重新决定：

- 中国东方巨物的光色和材质。
- 新的前景家族。
- 新的机位。
- 新的引导线。
- 天空、月球或地球是否需要保留。
- 母图怎样生成。
- 视频怎样从实际母图重新运镜。

例如题库里抽到“月洞窗外是云海仙山”，真正应该保留的未必是圆形窗户，而是：

> 一个非常亲密、可触摸的室内空间，突然收纳了一个世界尺度的外部景观。

适配时完全可以去掉圆窗，改成斜俯视、破开的殿墙、悬空长廊或水面倒影。

漫游保留的是问题，不是答案。

## 七、为什么选择直接公开 Prompt 原文题库

漫游模式的价值，不只是随机给出一个被压缩过的题目，而是让人能够看到一个视觉想法原本怎样组织空间、尺度、材质、光线和运镜。

如果仓库只保留抽象摘要，很多真正有启发的关系会在压缩中消失：某个前景怎样引向巨构，地球或月球怎样成为尺度参照，人物为什么必须极小，镜头速度怎样维持空间重量。

所以仓库直接公开 475 条 Prompt 原文，并把它设为漫游模式的默认题库。每条记录同时保留：

```text
id
prompt
post_url
author
content_hash
matched keywords
```

这样可以直接学习原文、按作者或主题筛选、固定种子复现抽题，也可以清楚比较“来源写了什么”和“东方巨物适配改了什么”。

仓库仍保留 24 条 HBG 原创视觉机制题卡，作为不读取长篇原文时的备用抽象题库。

公开原文不等于把它们声明成 HBG 原创。作者、来源 URL 和内容哈希必须保留；MIT License 只覆盖代码、Skill 文档和 HBG 原创题卡，不重新授权第三方 Prompt 文本。

## 八、巨物感不是“建筑必须看不完整”

早期我也认为，只要低机位仰拍、巨像冲出画面、人物站在脚下，巨物感就成立。

后来用户纠正：

> 应该不是完整展示的问题，应该是广角构图的问题。

这句话非常关键。

巨物可以完整出现。真正决定尺度的是：

```text
近处可读物体
+ 微小人物
+ 一座主巨构
+ 长引导线
+ 空气透视
+ 一个熟悉的环境或天体尺度
```

一座完整可见的巨门，只要它投下的阴影跨过街区、河流和人物，依然会比被裁掉顶部的普通高楼更巨大。

一个平视镜头，只要栏杆向远处收束、人物只有几个像素、地球弧面在天际保持稳定，也能产生比仰视更强的认知冲击。

所以三张以上的作品至少使用三类机位：

- 贴地低机位。
- 人眼平视。
- 斜俯视。
- 保留地平线的高空鸟瞰。
- 有选择地使用近垂直俯拍。

巨物不再等于永远仰视。

## 九、天空、地球和月球负责放大尺度，不负责替代文化

继续对比参考后，我们发现真正有冲击力的图往往会加入一个熟悉尺度：

- 清晰的云海地平线。
- 地球弧面和大气辉光。
- 一轮巨大的月亮或太阳。
- 日食。
- 行星地平线。
- 跨越建筑和天空边界的长桥、瀑布或河流。

观众不需要解释地球有多大、月球有多远。熟悉天体一进入画面，建筑和人物立即获得比较对象。

但每张只能有一个主要宇宙锚点。

天体一多，文化空间就会消失，画面也会变成通用太空歌剧。

飞船、全息界面、霓虹、多个巨大行星默认禁止。建筑、礼仪、材料和人物行为仍然必须属于当前题材。

## 十、参考图只能借“皮肤”，不能借“骨架”

参考图的材质和光线很好时，模型很容易把构图一起复制。

圆门、中央轴线、中央人物、对称庭院和树木框景，会在后面的每一张图里反复出现。

所以东方巨物 Skill 有一道参考防火墙。

允许继承：

- 清晰度和材质精度。
- 冷暖关系与色调。
- 云、雾、水和空气感。
- 电影质感和运动节奏。

默认禁止继承：

- 门的形状。
- 中央轴线。
- 对称布局。
- 人物位置。
- 树木框景。
- 庭院结构。
- 原始镜头和裁切。

适配之前必须先写新的构图声明。例如：

> 只保留参考图的材质、光色和空气感；构图彻底改成高位斜俯视、非对称开放全景。

## 十一、四个视频不是四次慢推

同一主题制作四个视频时，我会把它们定义成四种不同的发现方式。

| 镜头 | 空间任务 | 推荐机位 | 运镜 |
|---|---|---|---|
| 门槛 | 第一次遭遇巨物 | 贴地低机位或局部框景 | 慢推配合轻抬升 |
| 通路 | 进入文明内部 | 人眼平视、道路或水路 | 轴向推进或横移 |
| 揭示 | 解释巨构怎样成立 | 斜俯视 | 缓慢下降或高位侧移 |
| 崇高 | 把文明放入天体尺度 | 鸟瞰或选择性俯拍 | 后退揭示或稳定下降 |

四段共享材质、色彩、光线和东方巨物 DNA，但不共享同一个前景、构图和运动路径。

每段独立生成，检查建筑、人物和巨物稳定以后，再统一分辨率、帧率、音频和转场进行拼接。

这才是一个世界的四个章节，而不是一张图的四次变体。

## 十二、把这些经验变成 Skill，真正固化的是什么

这组三路 Skill 最终固化的是下面这些判断：

- 最难的是运镜和空间稳定，不是生成一张漂亮图片。
- 视频 Prompt 必须从实际母图重新写。
- 一种主运镜、一类环境运动、一个人物小动作。
- 远景巨构、天体、建筑和地貌必须刚性稳定。
- 东方巨物固定的是光色、材质、尺度和节奏，不是一种构图。
- 树只是前景家族之一，不能成为默认答案。
- 万物皆可巨构，一个词或碎片灵感就足够启动巨构转义。
- “写实”约束材质、光影和物理反馈，不约束概念必须现实。
- 寺庙加火山、海门加宫殿、村落加大屋顶不算足够荒诞。
- 关键词本身必须变成地貌、城市、天穹、天气、世界身体或物理法则。
- 巨构方案必须包含类别碰撞、不可能法则、人类栖居和至少三条尺度证据。
- 关键词扩写首先尊重题材，不保证自动变成中国天宫。
- 不喜欢关键词方向时，可以放下关键词进入漫游。
- 475 条公开 Prompt 原文用于学习奇观机制，不用于照抄最终风格。
- 漫游题库提供问题，东方巨物 Skill 提供统一电影语言。
- 原始 Prompt、来源、语义核和适配版必须分层保存。
- 巨物可以完整展示，广角关系比顶部裁切更重要。
- 每张最多一个宇宙尺度锚点。
- 四个镜头必须拥有不同的空间发现方式。

Skill 的价值，就是把“这一轮终于知道哪里不对”变成“下一轮默认不会再犯同一个错误”。

## 十三、完整工作流

```text
已有图片或明确场景
→ 直接进入东方巨物风格和运镜设计

只有一个国家、宗教、动作或碎片灵感
→ 关键词分类
→ 写出需要拒绝的现实版本
→ 让关键词本身发生巨构转义
→ 融合至少两种类别
→ 加入一个不可能法则和两项环境后果
→ 加入人类栖居关系和三条尺度证据
→ 荒诞度达到 8/10 后再扩写材质、人物和光线

不喜欢关键词方向，或者没有关键词
→ 从 475 条公开 Prompt 原文中漫游抽题
→ 保存来源
→ 提取语义核和尺度机制

选择最终题目
→ 套用东方巨物 Style Lock
→ 选择不重复的前景、机位、主体位置和引导线
→ 加入最多一个天空、月球、地球或行星锚点
→ 生成 16:9 母图
→ 检查构图复制、文化混搭、透视、人物和重复结构
→ 根据实际母图重新写 Gemini / Veo 运镜 Prompt
→ 锁定巨构，只允许一种主运镜和克制环境运动
→ 生成并抽帧检查每个视频
→ 所有镜头通过后再统一编码和拼接
```

这套系统不只适合天宫、仙侠和神话。

一个国家、一个宗教、一个人、一只动物、一件器物、一个动作、一轮月亮，甚至一句稀碎的感觉，都可以成为起点，也都可以成为巨构本身。

真正有冲击力的巨物，也不是把所有东西都做大。

而是通过前后景、人物、空气、天体和镜头速度，让观众在几秒钟里逐渐意识到：眼前这个世界，比自己第一眼理解的还要大得多。
