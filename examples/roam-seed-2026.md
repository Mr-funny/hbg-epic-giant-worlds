# Example: fixed-seed roam

Run:

```bash
python3 skills/hbg-oriental-giant-roam/scripts/roam_prompts.py --count 4 --seed 2026 --format markdown
```

The selector prefers different camera, foreground, and scale-mechanism families. The Agent then treats each selected card as a semantic question, applies the fixed Eastern Colossal Style Lock, and rewrites the actual video prompt only after each mother image exists.
